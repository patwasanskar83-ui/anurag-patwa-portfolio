Files:
- index.html: Complete responsive portfolio website (HTML, CSS and JavaScript in one file).

How to view:
1. Extract the ZIP file (if you downloaded the ZIP).
2. Open index.html in Chrome, Edge or Firefox.

How to publish free with GitHub Pages:
1. Create a GitHub repository, for example: anurag-patwa-portfolio.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will provide the public website URL after deployment.
